# High Noon art sources

Both raster assets were generated with the built-in imagegen tool for this project. There are no runtime generation services or image-generation dependencies. The supplied High Noon concept was used as a visual reference; its full screenshot is not a game texture. The game renders independent scenery, foreground, sprite, shadow, and HUD layers.

- `static/high-noon/street.png`: 1672 × 941 opaque street backdrop. Phaser covers the 1280 × 720 world with aspect preserved. The loaded texture is converted to neutral RGB before drawing.
- `static/high-noon/cowboy-sheet.png`: 1254 × 1254 transparent sheet, four columns by two rows. Runtime rounds cell boundaries, trims alpha, preserves proportions, places the boots on a common baseline, and prepares eight 96 × 176 nearest-neighbor frames. Alpha is preserved and RGB is made strictly neutral.
- `src/lib/games/high-noon/art.js`: original bitmap alphabet, HUD framing, foreground stones, and fallback procedural cowboy. The procedural sheet is only a fallback if the generated sheet cannot load.

To replace the cowboy, preserve the same eight-frame order and anatomy positions, or update `LOCAL_HITBOXES` and `FRAME_OFFSETS` in `model.js`. Check alignment with laptop hitbox debugging. To replace the backdrop, keep the center street clear and use a neutral landscape composition. Code enforces grayscale even when an input image contains small channel differences.

## Backdrop prompt

Create one standalone game BACKGROUND asset based on the attached High Noon concept reference. ONLY THE EMPTY OLD WEST STREET SCENERY: remove the cowboy completely, remove ALL top/bottom HUD panels, UI, borders, draw-time slider, crosshairs, hitboxes and overlay text. Fill the entire wide 16:9 image with a coherent SNES-inspired detailed 16-bit pixel-art western street. Saloon wooden building and shaded porch on left, DRY GOODS building on right, barrels, crates, wagon wheel, receding fences, desert mesas and clouds in distance. Keep center street empty for a separate cowboy sprite, standing center at 75% image height. Strong depth, crisp low-resolution pixel blocks, restrained contrast in empty center so sprite will read well. Strictly NEUTRAL GRAYSCALE ONLY: every pixel's R G and B must be equal, no sepia or tinted shadows, no colored pixels, no bright flashes. Compose as replaceable background layer for Phaser game, no people anywhere. Reference image defines mood, environment architecture and perspective only; do not copy screenshot HUD. Output wide landscape 16:9.

EXACTLY 8 frames in a perfectly uniform 4 COLUMN by 2 ROW grid, reading left to right then next row. Each cell same 1:2 width:height ratio. Overall sheet 2:1 landscape ratio, e.g 2048x1024 (cells512x512? Instead choose each cell256x512 and whole1024x1024: overall square image). FINAL SHEET SQUARE, 4 columns 2 rows, each cell256px wide512px tall. No gutters, no captions, no dividers. Each cell contains the SAME full-body front-facing Old West cowboy gunslinger in consistent detailed 16-bit SNES pixel art. Use chunky crisp pixels and selective gray highlights, worn dark long duster coat, pale button shirt, neckerchief, beard and mustache, broad brimmed black hat with visible eyes under shadow, gun belt, holster, wide-legged boots. Every frame same camera, same scale, same position: hat top about 3% cell height, boots baseline at97% cell height, center body at50% cell width. Torso at30-55% cell height, hip at57-70% cell height; hands beside body. Maintain body/hip registration across frames. Frames: top row 1 idle neutral hands near belt; 2 subtle idle breathing; 3 ready widened stance; 4 reaches right hand to holster. Bottom row 5 forearm lifting drawn revolver toward camera; 6 revolver fully aimed toward player; 7 non-graphic hit reaction shoulders recoil slightly, no blood; 8 recovering posture hands lowered. Full body in EACH cell with no cutoffs. No background scenery, no text, no shadows outside sprite, no blood, no muzzle flashes, no colored pixels. All opaque/visible pixels must R=G=B grayscale. This is a replaceable animated cowboy asset for a grayscale Western quick draw game, aesthetically similar to a detailed SNES Western sprite rather than simple vector art.
